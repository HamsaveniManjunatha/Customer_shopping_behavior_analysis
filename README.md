📊 Customer Behavior & Shopping Trends Analysis

An end-to-end data analytics project exploring retail customer behavior and shopping trends. The project follows a practical analytics workflow from raw data to business insights and an executive-ready Power BI dashboard.

## 🎯 Project Overview

Retail teams need to understand who their customers are, what they buy, and how shopping patterns change. In this project, I use Python, PostgreSQL, and Power BI to prepare the data, investigate business questions, and communicate the results.

**Dataset:** Customer shopping Behavior  
**Business focus:** Customer purchasing patterns, product preferences, subscription and shopping trends  
**Tools:** Python(pandas), PostgreSQL, Power BI

## ✨ What I Did

- 🐍 **Loaded the dataset into Python** and reviewed its structure, fields, and data types.
- 🧹 **Cleaned and prepared the data** by addressing missing values, duplicates, inconsistent formats, and data types where needed.
- 🔎 **Performed exploratory data analysis (EDA)** to understand customer and shopping patterns using summary statistics and visualisations.
- 🗄️ **Used PostgreSQL** to investigate business questions, compare customer groups, and summarise trends.
- 📈 **Built an interactive Power BI dashboard** to present key metrics and make the results easy to explore.
- 📝 **Created a step-by-step project report** documenting the data, methods, decisions, and findings.

## 🧭 Project Workflow

### 1. Understand the business context

Defined the project focus around retail customer behavior and shopping trends, then identified questions the analysis could help answer.

### 2. Load and inspect the data

Imported the dataset into Python with pandas and checked the number of records, column names, data types, and sample rows.

### 3. Clean and prepare the data

Reviewed data quality and prepared consistent, analysis-ready fields. Cleaning decisions were documented so the analysis could be understood and repeated.

### 4. Explore the data with Python

Used descriptive statistics and visualisations to examine distributions, customer segments, product preferences, and shopping patterns.

### 5. Analyse business questions with SQL

Loaded the prepared data into PostgreSQL and used SQL queries to filter, group, aggregate, and compare results relevant to the project questions.

### 6. Build the Power BI dashboard

Created visuals and interactive filters to communicate the main measures and trends. The dashboard is designed to help viewers explore the results without needing to read the analysis code.

### 7. Document the project

Prepared a report explaining the project objective, data preparation, EDA, SQL analysis, dashboard, key findings, and limitations.
